# 桌面键盘与本机剪贴板

## 背景

PC 浏览器和 Electron 客户端需要使用本机输入法控制远端应用。画布本身不可编辑，无法可靠承接中文输入法；工具栏操作可能留下本地控件焦点。原有粘贴仅读取纯文本，不能把截图等图片交给远端应用。

## 需求目标

连接桌面后，用户点击画面即可使用本机输入法；中文候选确认后文字恰好输入一次，不被解释成数字、Tab、退格或其他控制键，普通按键和组合键继续正常工作。手机系统键盘已确认的中英文、数字、空格和标点按原文送入应用，不被远端输入法再次收集成拼音预编辑；屏幕全键盘继续使用远端输入法。
本机已配置 Fcitx5 时，虚拟桌面可使用相同的输入法引擎、方案与静态词库，并在本会话内通过 Ctrl＋空格切换。首次使用时导入用户配置与静态数据，运行中的语言状态和学习数据库独立保存。物理会话与其他虚拟会话的输入状态不被切换。已运行的虚拟桌面可在更新后获得输入法服务而无需关闭现有应用。
键盘菜单提供直接发送 Ctrl＋空格的入口，供本机系统截获物理快捷键时切换远端输入法。该入口沿用远端快捷键配置，不修改本机系统设置。
反复使用组合键发送器或快捷键后，桌面继续接收键盘输入，断线、失焦或切换桌面后不残留按键。
用户通过本机粘贴快捷键或显式粘贴按钮，将纯文本或图片传到当前远端桌面；图片写入成功后才触发远端粘贴。
客户端本机剪贴板是复制粘贴的唯一内容来源。远端复制或剪切（含应用菜单）后同步到本机；用户粘贴时读取本机当前内容并传给当前远端桌面，不回退到远端残留内容。同步未完成时等待完成，同步失败时提示并阻止误贴旧内容。异步操作不能跨越断线或桌面切换。

## 范围

PC 浏览器、Electron 中承载的网页以及移动端已有输入代理；本机与当前远端之间的纯文本和图片复制粘贴。图片规范化为 PNG，传输上限 8 MiB，目标应用需要支持图片粘贴。

## 非目标

修改用户输入法或主机快捷键设置、文件传输、绕过浏览器剪贴板权限。
