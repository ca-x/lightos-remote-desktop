# 移动端桌面控制

## 背景

手机浏览器显示远端桌面画面，需要把触摸和本机软键盘输入发送到远端。画面流不提供远端输入框的语义信息，因此键盘由用户显式开关。

## 需求目标

移动端默认显示两行快捷键栏，按钮尺寸、字号、行间距和整体高度与 LightOS WebShell 底栏对齐。第一行最左侧固定为键盘按钮，其右侧为仅显示主页图标的返回 LightOS 管理页入口。点击键盘按钮展开软键盘，再次点击收起。
显示快捷键栏时隐藏悬浮入口，通过底栏菜单打开桌面工具。
键盘收起时，快捷键栏始终固定在页面可见区域底部并为系统安全区留位，不随桌面画面的长宽比或缩放位置移动。桌面画面在上方剩余安全区域内保持比例居中显示；底栏上缘只是画面的最大下边界，画面无需贴住底栏，底栏不能覆盖画面。
快捷键栏在键盘展开时位于键盘上方，操作按键不会收起键盘；中文组合输入和普通文字各发送一次。
用户可以点按、拖动、长按右键和双指滚动桌面；触摸取消、断线和切换桌面释放输入状态。
布局适配安全区、横竖屏与可见视口，键盘展开不会改变远端显示器分辨率。懒猫客户端采用管理页和 WebShell 相同的沉浸式声明，隐藏宿主导航区、保留系统状态栏，并自动消费宿主提供的四边安全区；普通浏览器使用系统安全区，宿主已处理的安全区不重复留白。
虚拟桌面跟随窗口时根据屏幕像素密度提高采集分辨率，并保持桌面逻辑尺寸与字体大小；物理桌面保持原有显示器分辨率和缩放。

## 范围

移动浏览器和懒猫客户端中的画面、触摸、软键盘、默认快捷键栏及视口变化；沿用现有远端输入协议。

## 非目标

远端输入框识别、修改主机键盘配置、快捷键自定义和终端专用会话操作。
