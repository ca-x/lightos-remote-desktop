# 移动端桌面控制

## 背景

手机浏览器显示远端桌面画面，需要把触摸和本机软键盘输入发送到远端。画面流不提供远端输入框的语义信息，因此键盘由用户显式开关。

## 需求目标

移动端默认显示两行快捷键栏，第一行最左侧固定为键盘按钮。点击按钮展开软键盘，再次点击收起。
显示快捷键栏时隐藏悬浮入口，通过底栏菜单打开桌面工具。
键盘收起时，快捷键栏位于桌面画面下缘并独立占用空间，不遮挡桌面画面。
快捷键栏在键盘展开时位于键盘上方，操作按键不会收起键盘；中文组合输入和普通文字各发送一次。
用户可以点按、拖动、长按右键和双指滚动桌面；触摸取消、断线和切换桌面释放输入状态。
布局适配安全区、横竖屏与可见视口，键盘展开不会改变远端显示器分辨率。
虚拟桌面跟随窗口时根据屏幕像素密度提高采集分辨率，并保持桌面逻辑尺寸与字体大小；物理桌面保持原有显示器分辨率和缩放。

## 范围

移动浏览器中的画面、触摸、软键盘、默认快捷键栏及视口变化；沿用现有远端输入协议。

## 非目标

远端输入框识别、修改主机键盘配置、快捷键自定义和终端专用会话操作。
