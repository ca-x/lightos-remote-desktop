# 桌面切换与连接恢复

## 背景

远程桌面用户可以在保留应用的虚拟桌面与本机已登录的物理桌面之间切换。
访问代理可能在连接关闭握手未完成时继续保持浏览器连接，导致切换长时间停在等待状态。

## 需求目标

用户切换桌面时，目标桌面可以及时连接，原连接完成关闭握手；无法确认原会话已释放时，用户在三秒内获得明确反馈并能主动恢复。
当服务端已经确认旧会话停止控制并释放控制权时，目标桌面可以立即连接，底层传输关闭在后台继续。
物理桌面不可用时，用户可在具备独立会话能力的设备上明确选择虚拟桌面。物理桌面由用户解锁，虚拟桌面由用户明确切换。独立虚拟桌面有自己的应用窗口，缺少能力或组件时明确说明不可用。
macOS、Windows 和 Linux 设备首次完成远程访问授权后，用户可以从外部网络连接仍在线且已登录的物理机。物理桌面锁屏时，远程界面展示系统锁屏画面，用户可在系统界面输入密码，解锁后在同一连接中继续使用原桌面会话。锁屏期间暂停桌面音频和剪贴板。系统策略禁止共享锁屏或系统授权被撤销时，连接页面说明原因。
连接失败最多自动重试两次，之后保留错误原因并允许手动重连。用户放弃初始化时，服务取消初始化并释放控制权。
任何时刻只有一个控制端能向桌面发送输入，返回虚拟桌面时原有应用仍然运行。
声音开启后播放当前桌面的音频：虚拟桌面使用隔离音源，物理桌面使用目标会话默认输出的监听音源。切换桌面或锁屏停止旧音频，不使用麦克风或其他桌面的音源回退；目标音频服务不可用时明确保持不可用。手机播放采用媒体播放模式，临时系统中断后用户操作可恢复声音，恢复失败提供可重试反馈并保持画面连接。

## 范围

桌面来源、物理显示器切换，连接关闭、初始化取消、失败反馈与重连。

## 非目标

更换采集或编码技术、物理桌面常驻采集、改变物理显示器分辨率。
