# 验收

- 同尺寸保持 Arc 身份；无放大，等比取偶数且符合现有 H.264 最小尺寸；拒绝无效尺寸和 RGBA 长度。
- 连续缩放复用缓冲，JPEG 和 H.264 可真实解码为目标尺寸，JPEG 保留彩色细节。
- WebSocket 能力协商后按显示上限编码；修改上限、切换清晰优先或原始大小后，静态桌面也能刷新，编码配置与实际尺寸一致。
- 浏览器按每帧 metadata 还原捕获尺寸；DPR、桌面分辨率菜单、自动分辨率、独立光标和输入仍使用各自正确的坐标空间。
- 旧服务端/客户端、原生尺寸路径继续工作；现有锁屏及编码中隐私 epoch 回归测试通过。
- 性能结论只报告所测链路，不声称端到端 FPS 或普遍带宽改善。
