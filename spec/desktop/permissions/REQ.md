# 远程桌面启动授权

## 背景

用户在 macOS、Windows 或 Linux 启动远程桌面时遇到权限或会话问题，程序直接退出且提示相同，用户难以找到正确的系统授权入口或判断具体原因。

## 需求目标

用户在懒猫远程开启桌面或主动申请权限时，由设备本机的实际被控程序请求缺少的系统权限。已授权的权限不再请求；用户拒绝或暂未完成授权时，不通过定时重试反复弹窗，也不采集或接受控制。

LPK 设备卡片分别显示屏幕录制和输入权限状态，并提供主动申请入口。设备上的系统提示与设置界面由本机系统处理；用户完成授权后，已请求开启的桌面自动重试启动。关闭远程桌面可取消等待中的请求并保持停用。

三平台都提供真实的屏幕与输入可用性检查。macOS 请求屏幕录制与辅助功能；Windows 检查图形采集能力、当前交互会话和系统隐私策略，系统提供可申请权限时发起请求或直达隐私设置；Linux 检查 X11/Wayland 的屏幕与输入能力，Portal 权限在实际连接会话中请求。锁屏、无显示器、系统不支持和系统策略禁止应分别说明，不能伪装成可通过弹窗解决的权限问题。

## 范围

macOS、Windows、Linux 运行时的权限诊断与系统支持的授权入口，以及管理卡片、独立控制程序和生命周期接入。权限授予仍由系统和当前 GUI 用户决定。

## 非目标

不自动授予、重置或绕开系统权限，不改变只读诊断和能力探测的行为，不新增自动真机测试。
