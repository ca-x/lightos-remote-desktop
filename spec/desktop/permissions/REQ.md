# 远程桌面启动授权

## 背景

macOS 用户首次启动远程桌面时缺少屏幕录制或辅助功能权限，程序直接退出，用户难以找到系统设置中的授权入口。

## 需求目标

客户端开启远程桌面并启动时，由实际被控运行程序请求缺少的系统权限。已授权的权限不再请求；用户拒绝或暂未完成授权时，不通过定时重试反复弹窗，也不采集或接受控制。

设置页分别显示屏幕录制和辅助功能状态，并可直接打开各自的系统设置页面。用户完成授权后返回客户端，自动重试启动。关闭远程桌面可取消等待中的请求并保持停用。

## 范围

macOS 运行时的显式权限请求接口，以及客户端启动、设置和生命周期接入。权限授予仍由系统和当前 GUI 用户决定。

## 非目标

不自动授予、重置或绕开系统权限，不改变只读诊断和能力探测的行为，不新增自动真机测试。
