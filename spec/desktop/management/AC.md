# 场景 1：在同一入口查看并连接有权访问的设备
ID: SC-OPENS-AVAILABLE-CONTAINER-AND-PHYSICAL-DESKTOPS
Profile: draft
Gate: required
Given 当前账号拥有可连接的容器和运行着控制程序的在线物理机，容器管理应用保持原版本
When 用户打开懒猫远程
Then 页面以带封面的卡片展示设备名称、系统和运行状态，应用名称为“懒猫远程”并使用新的黑白灰专用图标
And 卡片正文固定为设备名、系统和版本三行，直接点击预览进入对应桌面，预览底部居中以纯文字显示“点击进入桌面”，文字靠近下沿并位于向上淡出的深色渐变上，没有胶囊或毛玻璃，实例类型显示“LightOS实例”
And 设备名左侧显示实际平台标志，区分 Apple、Windows、Omarchy、Debian、Arch 和 Ubuntu，未知 Linux 发行版使用通用 Linux 标志，平台图标保留品牌原色而不统一黑白着色
And 版本行统一使用“懒猫远程”，物理机显示当前版本及可用的新版本；LightOS 来源提供版本时显示版本及“由 LightOS 管理”，缺少版本时显示“版本和状态由lightos管理”
And 物理机系统名后显示“权限已批准”或“权限未批准”；Windows 确认当前账户使用空密码且桌面可直接访问时显示“权限已批准”，隐藏锁屏授权提示和申请入口；需要锁屏授权且仅缺少该授权时显示“仅在桌面解锁时可访问”。需要授权时在文案右侧显示蓝色文字“请求设备权限”，与更新入口样式一致，不常驻展示屏幕录制或输入权限清单，标题下方说明为“懒猫微服网络保障您的隐私和数据安全。”，状态自动更新且没有刷新按钮
And 滚动设备列表时顶部标题和主题操作保持吸顶可见，内容经过顶部栏时不与标题重叠
And 明暗主题均使用黑白灰界面，在微服沉浸模式中尊重宿主安全区，设备操作不会被状态栏或关闭按钮遮挡
And 已安装且已授权的在线物理机在总开关开启、服务空闲时显示“点击进入桌面”，离线设备不显示

# 场景 2：从管理页管理默认开启的物理机远程桌面
ID: SC-PERSISTS-PHYSICAL-DESKTOP-ENABLEMENT
Profile: draft
Gate: required
Given 用户首次运行包含常驻控制模块的客户端，已登录微服，“接入 LightOS”保持关闭
When 用户从另一台设备打开懒猫远程查看该设备
Then 尚未安装桌面时设备仍可见并显示安装入口，首次安装后总开关默认开启，控制模块仍在线，PC 设置页没有远程桌面开关
When 用户首次安装后查看设备，尚未打开桌面窗口
Then 卡片显示“运行中”，服务保持空闲，未获批准的系统权限仍有提醒，用户可直接发起授权并在被控设备确认
When 用户完成必要授权并从另一台设备点击预览
Then 桌面服务自动启动，窗口就绪后可查看和操作设备
When 最后一个桌面连接断开且 5 秒内没有重连
Then 服务停止，卡片仍显示“运行中”，再次进入会启动服务
When 连接期间用户从图标菜单选择“关闭远程桌面”
Then 现有连接断开，服务停止，卡片显示“已关闭”。管理服务或控制程序重启后，预览和已保存的链接都不能启动桌面，直到用户再次开启

# 场景 3：远程桌面与终端分别授权
ID: SC-DESKTOP-INDEPENDENT-OF-TERMINAL
Profile: draft
Gate: required
Given 用户已登录微服，物理机运行独立控制程序且“接入 LightOS”关闭
When 用户从懒猫远程开启并连接该物理机，再开启和关闭“接入 LightOS”
Then 桌面可查看和操作，终端设置变化不改变桌面连接
When 用户切换客户端当前登录账号
Then 旧账号不能继续控制或连接当前设备，新账号独立使用默认开关，桌面进程等待该账号发起连接

# 场景 4：离线设备隐藏并在上线后恢复卡片
ID: SC-HIDES-OFFLINE-DEVICES-AND-RESTORES-ONLINE-CARDS
Profile: draft
Gate: required
Given 当前账号曾管理另一台物理机并保存过连接预览
When 该设备离线或管理应用重启
Then 该设备从页面和在线计数中移除，页面没有离线设备列表
When 设备重新上线并完成登记
Then 卡片自动重新出现并沿用原有封面，无需手动刷新
And 其他账号不能读取该设备的控制信息或预览

# 场景 5：从微服安装匹配平台的桌面程序
ID: SC-INSTALLS-MATCHING-RUNTIME-FROM-LPK
Profile: draft
Gate: required
Given 当前账号拥有另一台尚未安装远程桌面的在线设备，客户端控制模块已运行，LPK 已构建当前系统和架构的程序
When 用户在设备卡片点击安装远程桌面
Then 卡片显示真实安装进度和状态，设备只从当前微服应用域名下载匹配平台的程序并校验
And 首次安装完成后显示已安装版本和“运行中”，桌面服务等待连接，未授权权限可从卡片主动申请
When 从图标菜单卸载远程桌面并刷新设备列表
Then 原托管版本目录已删除，卡片显示“安装远程桌面”；重启管理服务后仍可通过该入口重新下载安装，Windows 已批准的锁屏授权组件保留
And 未安装或版本不一致时只提供对应的安装或更新入口，具备安装更新能力时不额外展示客户端升级提示，安装或更新入口位于版本右侧，卡片底部没有操作区

# 场景 6：确认中断后更新正在运行的桌面
ID: SC-CONFIRMS-INTERRUPTION-BEFORE-UPDATE
Profile: draft
Gate: required
Given 设备已开启远程桌面且正在被连接，LPK 提供不同版本
When 用户点击版本右侧的蓝色“更新远程桌面”文字
Then 弹窗说明更新会中断当前连接，并提供取消和确认
When 用户取消
Then 桌面与当前连接保持可用，安装没有开始
When 用户再次点击更新并确认
Then 当前连接被结束，服务自动停止并开始下载安装，无需手动断开或停留在等待连接结束的进度
And 完成后恢复原有开启状态、显示新版本、删除旧版本二进制并立即隐藏进度和完成提示

# 场景 9：保留本机卡片并阻止循环连接
ID: SC-SHOWS-CURRENT-DEVICE-AND-BLOCKS-SELF-CONNECTION
Profile: draft
Gate: required
Given 微服能够识别当前客户端的设备身份，当前账号已登记该物理机及其他可访问设备
When 用户打开懒猫远程或等待自动刷新
Then 在线本机保留在列表及在线计数中，预览连接入口禁用且文案为“当前设备”
And 本机的安装、更新、权限与启停入口按实际状态保持可用，管理服务重启后继续识别本机
And 其他设备与 LightOS 实例保持可见，不因名称或操作系统相同而被隐藏
When 用户打开先前保存的本机桌面连接地址
Then 连接被阻止并提示从另一台设备访问
When 用户从另一台设备打开懒猫远程
Then 原设备仍按正常在线、权限和运行状态显示并可连接

Gate: required

# 场景 11：卡片状态与错误变化保持尺寸稳定
ID: SC-KEEPS-DEVICE-CARDS-STABLE-DURING-STATUS-CHANGES
Profile: draft
Gate: required
Given 同一视口下展示在线物理机和 LightOS 实例卡片
When 物理机总开关在运行中和已关闭之间切换，或出现长错误、权限提示及安装更新进度
Then 状态位于预览左上角，使用小尺寸圆角胶囊、通透底色、同色文字及左侧圆点，不设边框并靠近预览左上角；运行中为绿色、已关闭为灰色，背景不使用模糊或毛玻璃
And 错误位于状态下方的主题纯色文本块内，进度位于预览覆盖层，长文本不会撑高卡片
And 正文保持紧凑的三行，各行间距相等且跨卡片对齐，同行文字与操作入口居中对齐；纯图标菜单位于设备名右侧，展开后依次提供远程桌面开关、防休眠和卸载项，权限入口位于系统名右侧，安装更新位于版本右侧，卡片底部没有独立按钮区

# 场景 12：Linux 物理机按实际授权方式提供操作
ID: SC-LINUX-PHYSICAL-PERMISSION-GUIDANCE
Profile: draft
Gate: required
Given 用户通过 PC 客户端接入 Linux 物理机
When 用户查看权限状态并开启、连接远程桌面
Then 已可用的设备直接连接当前真实桌面，连接时确认的设备明确提示在被控机批准屏幕与输入访问

And 系统提供可恢复授权时，断线、运行时重启和升级后继续使用已批准授权，不重复要求确认；系统撤销或授权失效时重新确认

# 场景 15：未授权设备提供独立的权限申请入口
ID: SC-REQUESTS-PHYSICAL-PERMISSIONS-WITHOUT-NAVIGATION
Profile: draft
Gate: required
Given Linux 物理机具备桌面共享能力但尚未授权，已安装支持独立申请的运行时
When 用户在系统名右侧点击“请求设备权限”
Then 留在管理页显示申请进度和结果，不直接跳转到桌面页面，也不改变原有桌面启停意图
And 成功保存授权后隐藏权限申请入口，预览连接入口只负责进入桌面
And 取消、拒绝或无法保存授权时显示真实结果，不把未完成的申请标记为成功
And 状态刷新仅重新获取诊断结果，不触发系统授权或重复弹窗
When 用户直接连接尚未授权的物理桌面
Then 等待页面明确提示在被控电脑确认权限，确认后自动显示画面

# 场景 16：旧客户端无法更新时说明升级前置条件
ID: SC-EXPLAINS-PC-CLIENT-UPDATE-PREREQUISITE
Profile: draft
Gate: required
Given 在线物理机因旧 PC 客户端不具备安装更新能力，卡片存在安装或更新入口且没有正在处理的操作
When 用户打开懒猫远程查看该设备卡片
Then 安装或更新入口保持禁用，卡片直接提示先更新并重启被控设备上的懒猫 PC 客户端，中文与英文均可读且无需鼠标悬停

Then 页面自动移除客户端升级提示，安装更新入口按实际状态恢复，不自动开始安装或更新

# 场景 17：管理物理设备的持久防休眠
ID: SC-MANAGES-PERSISTENT-HOST-SLEEP-POLICY
Profile: draft
Gate: required
Given 已安装支持此功能的运行时，设备在线，未建立桌面连接
When 用户展开 macOS、Windows 或 systemd Linux 设备菜单
Then 卸载上方根据设备当前电源设置显示“申请禁用休眠”或“关闭防止休眠”，读取状态不会弹出授权
When 用户在允许休眠的设备上申请禁用，按系统要求在该机确认
Then 核实系统已应用后显示“关闭防止休眠”，接电、电池、合盖和重启后均继续生效
When 用户在系统授权窗口取消或拒绝
Then 提示操作未完成，重新读取真实设置，保留原有远程桌面开关和连接状态
When 用户关闭防止休眠
Then 优先恢复开启前的电源设置；设备已自行禁用休眠且没有备份时，恢复常规休眠配置并回读结果
When 菜单收起、切换到另一张卡片、页面隐藏或关闭
Then 停止查询原设备的休眠状态，重新展开时读取最新状态
