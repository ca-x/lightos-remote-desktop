# 远程桌面会话工具与设置窗口

## 背景

远程桌面用户通过悬浮工具栏调整画面、输入和连接设置。重复的说明与关闭入口占据空间；设置页随内容改变高度，切换标签时窗口跳动；桌面列表和接入状态需要手动刷新。

## 需求目标

悬浮按钮与展开工具栏形成连续的胶囊外壳，只有一个展开和收起按钮。展开时背景从透明渐显，再延伸显示工具；收起沿相反路径回到透明按钮，快速反向操作从当前状态继续。四边停靠都横向展开；顶部和底部停靠时比较左右可用宽度，朝空间更大的一侧展开，收起时顶部箭头向下、底部箭头向上；展开时平滑旋转成左右箭头，指向收起方向。窄屏空间不足时工具可以横向滚动访问，不变为竖栏。拖动结束后从最后显示的位置自动吸附到最近的屏幕边缘，沿该边缘的位置随松手位置保留，无需先拖到边缘；浏览器丢失指针捕获也完成吸附，不退回原位置，明确取消拖动时才恢复原停靠。

连接状态小点仅在工具栏展开时显示，位于电脑图标左侧，收起的悬浮按钮不显示状态小点。工具栏只显示功能图标，移除品牌名称、品牌图标和独立连接按钮，功能图标保留可访问名称和悬停说明。悬浮按钮收起时，悬停和按压保持透明，只有展开后才显现工具栏背景。悬停和点击时使用可点击光标，达到拖动阈值后使用拖拽光标。拖动过程中实时预览对应停靠边缘的收起箭头，顶部向下、底部向上；松手后保持该方向，展开时再旋转为对应的左右箭头。连接信息菜单中的“关于”上方不提供连接或断开连接选项。

界面沿用 LightOS 管理页的明暗背景和卡片层次，交互强调使用中性灰，移除蓝色的悬停、选中、按压、图标与文字强调。以背景色块、间距和轻微的颜色变化区分区域、悬停、选中与按压状态，菜单项之间保留独立间隔，选中与相邻悬停背景不贴合，不为这些状态添加线条框；键盘导航仍有可识别的焦点提示。桌面端工具栏高度为 40px，触摸操作保留足够的点击区域。关于介绍为“保障您的隐私和数据安全。”。

设置、键盘和剪贴板窗口使用视口高度的固定比例，标签和右上角关闭入口保持可见，键盘及剪贴板窗口保留各自标题，内容超出时独立滚动。切换标签或刷新数据不改变窗口外框高度与位置。设置窗口不显示“设置”标题文本，没有底部栏及“完成”按钮，Tab 栏与滚动内容之间保留固定底部间距。RDP、MCP 等表单的文字标签在上、输入框在下，标签和控件之间保留独立间隔，长地址和指纹输入框占满可用行宽。

所有可见下拉选项使用页面自绘列表，不打开系统选择器，保持既有值、禁用状态和保存方式；支持方向键、输入定位、回车选择和 Esc 关闭，关闭后返回触发控件。设置窗口、菜单、选项列表、文字框、桌面原始大小视口和横向工具栏统一使用页面绘制的细圆角滚动条，滚动或靠近边缘时显示，闲置后淡出；保留滚轮、触摸、键盘滚动及桌面端滑块拖动，不出现两套滚动条。

删除通用桌面操作说明、FPS/RTT 解释以及偏好保存提示；偏好继续自动保存，手动分辨率继续由用户应用。桌面来源、显示器列表以及可见的 MCP/RDP 设置自动更新，没有手动刷新入口。后台刷新保留用户正在编辑的内容，不切换桌面或打断提交；隐藏页面停止刷新，恢复可见后更新。

## 范围

浏览器远程桌面的会话工具栏、设置窗口、键盘与剪贴板窗口，以及这些界面的桌面发现和接入状态刷新。

## 非目标

改变远程画面和输入协议、自动读取剪贴板、修改连接重试策略或新增自动真机验收场景。真实设备上的画面与交互由开发者手工验收。
