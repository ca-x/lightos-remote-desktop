# v0.1.15: Linux desktop backends and session safety

- Fix the Ubuntu 22.04 release build by pinning a private SPA header SDK for the Rust bindings while retaining the system PipeWire library and glibc baseline. Package the SDK provenance and copyright notice. The v0.1.14 tag did not produce a public release.
- Separate capture, input, clipboard and lifecycle behind `DesktopBackend`, keeping display control, distribution detection and desktop initialization independent. Web, MCP and RDP consume the shared interface.
- Resolve one trusted same-user Wayland or local X11 session before selecting a backend. Probe actual capabilities with bounded, noninteractive checks; keep explicit targets and reject ambiguous sessions rather than using XWayland as Wayland capture.
- Add native X11 capture, XTest input, Unicode text and clipboard with explicit display/authority and a private worker. Core image reads are the current capture path; SHM/Damage and performance parity are not claimed.
- Add optional shared Portal RemoteDesktop/ScreenCast/Clipboard authorization and PipeWire capture. Official binaries include it; the selected socket must match one verified GNOME/KDE provider and compositor. Discovery and daemon startup never request consent; failed authorization requires an explicit new attempt. GNOME/KDE hardware and fractional-scaling acceptance remain unverified.
- Gate physical capture, input and clipboard on the exact session's lock state. Clear cached frames and release input on lock; resume only with a newly captured frame after unlock.
- Preserve Hyprland monitor rotation and placement during owned desktop resize, including Lua-based configurations. Diagnostics distinguish owned startup from persistent, Wayland and X11 attachments and separate required tools from optional helpers.
- Fix the About logo under the production Content Security Policy. Use transparent directional toolbar triggers, retain the 48-pixel About logo, and preserve menu placement when the toolbar is dragged to any edge.
- Keep binary-generated systemd units as the source of truth. Explicit Wayland/X11 attachment overrides the packaged persistent-session default; older owned transport recovery retains the legacy setting needed for handoff.
- Retain tag-driven GitHub Release, Arch codec and AUR publication. Production installation remains managed by the user through AUR.
