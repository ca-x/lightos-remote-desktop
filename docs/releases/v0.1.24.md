# v0.1.24: desktop input and GPU selection

- Keep rotated and mirrored Wayland monitors upright in the reusable capture path.
- Fix Portal text input for line breaks, tabs and Latin-1 characters, including pasted CRLF line endings.
- Add host-side VA-API device and NVENC GPU selection for dedicated and hybrid GPU setups, without silently switching away from the selected adapter.
- Refresh hardware availability after detected adapter, driver-version, device-permission or encoder-device selection changes.

GPU selection requires matching core and optional encoder-worker packages;
configuration is described in [hardware encoding](../hardware-encoding.md#dedicated-and-hybrid-gpu-selection).
Automatic selection and software fallback remain available without overrides.
Dedicated/hybrid GPU operation and rotated physical monitors still require
validation on the target hardware; this release does not add GPU zero-copy or
claim a measured performance improvement.

## 中文

- 旋转或镜像的 Wayland 显示器也可使用复用采集缓冲的路径，画面保持正确方向。
- 修复 Portal 文本输入中的换行、Tab 和 Latin-1 字符，粘贴 CRLF 文本时不再多出换行。
- 新增主机侧 VA-API 设备和 NVENC 显卡指定，便于独显、混合显卡环境选择编码设备，失败时不会悄悄换用另一张卡。
- 检测到显卡、驱动版本、设备权限或编码设备选择变化后，重新探测硬件编码能力。

指定显卡需要同时更新主程序和可选编码器包；未设置时保持自动选择和软件回退。
独显、混合显卡及旋转物理屏仍需在目标硬件上验收，本次未加入 GPU 零拷贝，
也不宣称已经测得性能提升。现有服务名称和默认桌面保持不变。
