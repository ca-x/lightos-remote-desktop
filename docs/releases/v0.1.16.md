# v0.1.16: viewport-aware streaming and desktop clarity

- Fit and fullscreen modes encode only the device pixels needed for the visible picture, using FIR SIMD and reusable buffers; quality-first, actual-size mode and magnified physical desktops retain native video.
- Keep desktop resolution menus, automatic resolution, normalized input and cursor coordinates independent of encoding size, preserving local picture zoom and pan when the video dimensions change.
- Include the native cursor channel with shape, hotspot and density handling, an optional ABI-checked Hyprland observer, and embedded-cursor fallback on unsupported sessions.
- Improve virtual desktop text density on high-DPI displays, preserve JPEG 4:4:4 color detail, support image clipboard on available backends, and retain the Hyprland resize validation.
- Recognize UWSM physical login sessions, discover physical desktops outside the transport runtime, and keep the retained virtual desktop selectable after a transient physical connection.
- Isolate physical picture zoom from page controls and respect WebShell/Lazycat safe areas, mobile dock space and two-finger scrolling.

Targeted CPU tests measured about 16-25% less encoding preparation/encode time in the documented synthetic scrolling cases at 2/3 scale, including blocking dispatch and Arc transfer. Capture, network, ACK pacing and browser presentation are excluded; these measurements do not establish end-to-end FPS or universal bandwidth savings. Hardware/GPU scaling and real GNOME/KDE hardware acceptance remain unverified. Conditions and raw results are in `docs/encoder-scaling.md`.

Both AUR bin packages advance to 0.1.16 through the existing automatic publication chain. Service names, paths and the persistent desktop owner stay compatible with the existing installation.
