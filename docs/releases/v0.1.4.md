# v0.1.4 · 修复全屏画面模糊

## Changes

- Fix switching from a manually reduced virtual desktop resolution to fullscreen so a stale resize request no longer leaves a low-resolution image stretched across the screen.

## Validation and limits

Two regression cases cover both pending and completed earlier automatic resize
requests. A real browser reproduces the previous 320×200 image stretched to
576×360; with the fix, the fullscreen canvas and displayed image both reach
640×360 in the same test viewport.

This fixes a resolution-switching bug, not all possible sources of image blur.
Encoder quality, bitrate, HiDPI handling and physical monitor resolution are
unchanged. Existing runtime requirements and single-binary distribution remain
the same as v0.1.3.
