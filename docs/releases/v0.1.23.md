# v0.1.23: native Niri sessions and capture fixes

- Add opt-in native Niri remote sessions using the owner's existing configuration,
  with private startup environment validation and desktop persistence across
  transport upgrades.
- Resize owned nested desktops without closing applications, while keeping
  physical desktop capture at its original dimensions.
- Reuse Wayland capture buffers and share Linux hardware-encoder frames without
  copying raw frames through a pipe.
- Fix native FFmpeg color conversion on older FFmpeg releases and build the
  cursor companion against both Hyprland 0.56 and 0.57 headers.
- Bound cancelled native-session startup and reject private log aliases without
  following links or truncating unrelated files.
- Refine desktop settings, scrolling and mobile keyboard menus, including
  reopening the toolbar from the mobile keyboard controls.

The default owned desktop remains Hyprland; Niri requires explicit selection
and an existing configuration. Selecting a physical desktop never substitutes
a separate virtual session. The Hyprland companion still requires headers
matching the running compositor; this release does not replace it with a
version-independent capture implementation. GPU performance and physical
desktop behavior still require validation on the target machine.

新增可选的原生 Niri 远程会话，调整自有嵌套桌面的分辨率时保留应用；物理桌面保持
原始采集尺寸。修复 FFmpeg 转换崩溃并兼容 Hyprland 0.56／0.57 的光标组件编译，
同时改进桌面设置、滚动和移动端键盘菜单。默认桌面与现有服务名称不变，不自动
迁移用户桌面，也不在本次替换光标采集架构。
