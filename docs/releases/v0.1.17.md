# v0.1.17: physical desktop startup recovery

- Recover stalled native Wayland physical desktop startup with up to two retries within the existing ten-second connection budget.
- Keep the mobile tools menu available before connection readiness and after failure, so users can reconnect or switch desktops while remote input stays disabled until ready.
- Show a disconnected desktop hint pointing to the recovery menu.

Both AUR bin packages advance to 0.1.17 through the existing automatic publication chain. Service names, installation paths and the persistent desktop owner remain compatible with the existing installation.
