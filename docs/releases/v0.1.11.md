# v0.1.11: 新工具栏与 AUR 安装更新

## Changes

- Compact toolbar with display, keyboard, clipboard and connection menus; independent settings dialog for streaming, appearance and MCP. Menus follow all four docking edges, remain accessible on small screens and work inside fullscreen. Existing preferences and active connections survive opening settings.
- Unified executable and release archive names: `lightos-remoted` and `lightos-remoted-linux-x86_64.tar.gz`. The optional `lightos-codec-ffmpeg` keeps its existing name. Project code is now licensed under MIT; third-party notices remain included.
- AUR package `lightos-remoted-bin` installs the executable under `/usr/lib/lightos-remoted`, with `/usr/bin/lightos-remoted` as the command. Fresh installs initialize and start both services. Normal upgrades restart the transport while preserving the desktop owner and its applications.
- Existing LightOS service names and authentication files are retained. Legacy manual installations remain running until the user follows the README migration steps; obsolete local service overrides must be removed during that migration.

## Validation

- Frontend: 91 Node and 23 Vitest tests passed. Workspace all-feature suite: 162 tests passed; strict all-feature Clippy, formatting, release build, 43 installer and 13 compatibility checks passed.
- Real browser checks covered 32 menu placements after dragging to four edges and four corners, narrow and landscape viewports, focus trapping/return, dark/light themes and reduced motion.
- An isolated native desktop delivered H.264 frames to the redesigned interface, kept its connection across menu/settings interactions and displayed settings inside fullscreen. Served JavaScript/CSS matched the built assets. This integration harness used a local authentication proxy; a direct authenticated WebSocket handshake was checked separately.
- AUR packaging includes bootstrap/release guard fixtures and a real nonroot makepkg build of its private patched Aquamarine library. No package installation or production service migration was performed on the development host.

## Installation and migration

After AUR publication, install with `yay -S lightos-remoted-bin` and update with `yay -Syu`. See [AUR details](../aur.md) and the [old-install migration instructions](../../README.md#老用户迁移与清理旧版手动安装).

The private Aquamarine compatibility library targets Aquamarine 0.15.1 / SONAME 14 and must be revalidated when Arch changes that ABI. Fresh dedicated-user systemd activation was covered with fixtures rather than a fresh-machine deployment. Optional hardware encoding, MCP and RDP retain the setup requirements and limits documented in v0.1.10.
