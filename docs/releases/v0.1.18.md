# v0.1.18: capture and encode performance

- Connect with validated software codecs while hardware checks run in the background, then apply available hardware according to the saved preference.
- Reduce frame copying and serialization work in the optional codec worker and reuse FFmpeg conversion buffers without overwriting retained frames.
- Convert only the newest queued Portal frame and reuse capture storage when ownership permits.
- Automatically use X11 shared-memory capture and damage tracking when supported, with core capture fallback when unavailable.

Both AUR bin packages advance to 0.1.18 through the existing automatic publication chain. Local worker-packing measurements and their limits are recorded in [capture/encode performance](../capture-encode-performance.md); they do not establish end-to-end FPS or network savings.
