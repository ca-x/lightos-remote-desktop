# v0.1.0

首个 Rust 原生版本，面向已有 LightOS 远程桌面服务的 Linux x86_64 环境。

1. **浏览器远程桌面**：提供独立 Omarchy 桌面会话，支持键鼠、文字剪贴板和可选声音，画面使用 H.264 或 JPEG。
2. **显示与工具栏**：支持跟随浏览器分辨率、适应窗口、原始大小和全屏，悬浮按钮可拖到四边并记住位置，工具栏显示 FPS、RTT/P95、编码和分辨率。
3. **通用键盘控制**：全屏时尝试捕获所有可用按键，也可自由选择 Ctrl、Alt、Shift、Super 与主键组合，直接发送到远程桌面，不绑定特定快捷键。
4. **服务安装与回滚**：程序可将自身安装为服务，替换现有 LightOS Python 服务，并保留迁移备份与上一事务回滚能力。
5. **应用启动兼容**：修复远程会话未传递显示环境的问题，菜单启动的 Ghostty 和需要 X11 的 v2rayN 已在候选会话中验证显示。

## 安装

下载 `lightos-remote-desktop-linux-x86_64.tar.gz` 和对应 `.sha256` 文件后执行：

```sh
sha256sum -c lightos-remote-desktop-linux-x86_64.tar.gz.sha256
tar -xzf lightos-remote-desktop-linux-x86_64.tar.gz
cd lightos-remote-desktop-linux-x86_64
./lightos-remote-desktop install-service --dry-run
sudo ./lightos-remote-desktop install-service
```

要求已有 LightOS 服务及其认证配置，并预先准备 Cage、Hyprland、FFmpeg、
私有兼容库等运行依赖；安装器不会自动下载安装这些依赖。完整要求见包内 README。

需要回滚时执行 `sudo ./lightos-remote-desktop rollback-service`。
回滚恢复上一安装事务，不保证直接回到最初 Python 版本。

## 已知限制

- 这是独立远程桌面，不是物理屏幕镜像，尚未达到完整 Selkies 功能或性能对等。
- 当前使用 CPU 采集/编码，未实现 GPU 编码或零拷贝；音频为 PCM，不支持麦克风上行。
- 用户反馈的卡顿仍在排查，RTT 是应用层往返时间，不是操作到画面的完整延迟；静止画面跳过重复帧，低 FPS 不一定代表卡顿。
- 键盘捕获需要浏览器支持和权限，通常要求 HTTPS 或 localhost；本机系统保留键仍可能先被截走。
  可用工具栏通用组合键发送器兜底，`Ctrl+Alt+Shift+Esc` 释放捕获并打开工具栏。
- 当前仅提供 Linux x86_64 二进制。
