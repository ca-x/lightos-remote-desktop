# v0.1.12: Short runtime paths for Hyprland

- Use `/run/lrd-session` consistently in the binary-owned desktop and transport units, with private directory permissions. This fixes desktop startup failures caused by Hyprland IPC socket paths exceeding the Unix socket limit.
- Check owner runtime paths before launching desktop children. Errors now identify the path limit and suggest a shorter directory instead of waiting for startup to time out.
- Preserve live desktops across transport upgrades by validating and reusing the previous managed runtime until the owner is explicitly restarted.
- Remove only the exact paired v0.1.11 `60-short-runtime.conf` workaround through the shared installer. Modified, partial and symlinked overrides remain untouched.
- AUR continues to export units from the release binary. Both binary packages follow the existing tag → Release → Arch worker → AUR automation.

This release does not change hardware encoder support or resolve host driver initialization failures. The existing software encoding fallback remains available.
