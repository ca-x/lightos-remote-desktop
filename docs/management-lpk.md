# 独立远程桌面应用

LPK 显示名称为“远程桌面”。管理页、管理服务、专用图标和 LPK 构建均属于本仓库。
页面只列出当前账号可连接的桌面并提供刷新与连接，不包含分类、搜索或打开其他
管理应用的入口。保留原应用包 ID 以便覆盖升级，不要求卸载已有应用。

## 桌面来源

管理服务消费已有接口返回的连接 URL，不改写来源的桌面设置，不要求来源添加
新接口。`REMOTE_DESKTOP_SOURCES` 可配置 `{app_id,name,path}` 数组；默认容器
来源使用已安装容器管理应用的既有 `/api/list` 和 `remote_desktop_url`。
不使用曾新增的 `/api/remote-desktop/targets`，不要求升级 LightOS。

跨应用调用遵循平台的 [用户委托机制](https://developer.lazycat.cloud/advanced-app-interconnect.html)：
LPK 声明 `lzcapp.user_delegate`，只转发真实请求中的 `X-HC-User-Ticket` 到来源应用的
`app.<app_id>.lzcx` 入口，由系统验证用户身份。公开域名从平台自己的应用域名查询
接口取得。来源未安装可以为空；来源授权或网络失败时显示部分来源不可用，并保留
其他可用来源的桌面。不会使用管理员固定身份代替当前用户，也不回显用户票据。
平台后续需要显式授权时，应沿用其授权流程，不能自行制造票据或绕开身份检查。

物理机由客户端直接调用本应用的 `POST /api/hosts` 登记和续期，35 秒未续期后
不再提供新的连接。登记仅接受已登录账号拥有的在线设备；公开列表不包含密码、
端口、终端密钥或用户票据。连接时再次核对归属、在线状态和接入代次，经平台
设备通道访问本机回环地址。客户端退出、切换账号或关闭远程桌面后停止运行时，
已打开的连接随之断开。无需修改容器管理应用来存储物理机的远程桌面字段。

## 构建与手测

在本仓库根目录执行 `lzc-cli project build`，输出到 `dist/`。
管理服务将页面和专用 PNG 图标嵌入程序，安装包图标使用同一个 PNG。
桌面客户端的本机运行时、生命周期和设置继续由客户端自己的构建流程交付。
本次调整物理机登记地址后，需要重新构建客户端；旧客户端没有独立登记能力。

使用新 LPK 在指定账号和设备上手动确认：

1. 保持现有容器管理应用版本，确认管理页直接列出已有桌面，点击原有 URL 可连接。
2. 页面和应用名称为“远程桌面”，使用专用 Logo，没有分类、搜索或其他应用入口。
3. 新客户端开启远程桌面后出现在同一列表，关闭、切换账号或退出后旧连接失效。
4. 登录失效显示重新登录提示，某个来源不可用不清除其他来源的可用桌面。
5. 分别验证各系统的画面、键鼠和系统权限；编译或 HTTP 成功不能替代这些手测。

不新增自动真机场景，不将静态检查、临时调试服务或旧版本接口观察报告为完整产品验收。
