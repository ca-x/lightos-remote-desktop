# 移动端操作

触摸设备默认显示两行快捷键栏，尺寸与 LightOS WebShell 对齐：按键高 28px、字号 12px、图标 18px、行间距 4px、上下各 8px，底部安全区另行计入。第一行最左侧的键盘图标固定可见：点按展开软键盘，再次点按收起；第二行菜单按钮右侧的主页图标返回同一 LightOS 管理入口，即使远程连接未就绪仍可使用。桌面画面本身的点按用于远端点击和定位光标。
显示快捷键栏时隐藏悬浮按钮，通过第二行左侧的菜单按钮打开桌面工具。连接未就绪或失败时菜单和主页入口仍可使用，可查看原因、重新连接或切回虚拟桌面；远端输入按键等待桌面就绪后启用。

快捷键栏始终固定在可见页面底部。适应窗口模式中，桌面画面在底栏上方剩余安全区域内保持比例居中，底栏上缘只是画面的最大下边界；宽画面可以留白，底栏不随画面移动。键盘展开后，底栏跟随可见视口停靠到键盘上方。1:1 模式的滚动区域同样为底栏留出空间，物理桌面的局部缩放只作用于画面，可见内容仍裁切在底栏上方。

懒猫客户端使用与管理页、WebShell 相同的导航栏隐藏声明，保留系统状态栏，不主动切换宿主全屏状态。布局优先消费 `--lzc-safe-area-top/right/bottom/left`，未注入时使用浏览器 `env(safe-area-inset-*)`；宿主明确提供 0 时不重复添加安全区。安全区或横竖屏变化会重新计算画面可用尺寸和工具栏位置。键盘确实展开后移除底栏的底部安全区留白；仅输入框获得焦点、未弹出软键盘时仍保留。

快捷键沿用 WebShell 的双行布局及一次性修饰键交互：Ctrl、Alt、Shift、Super 高亮后作用于下一次按键，执行后恢复。方向键、Enter、退格和 Delete 支持按住重复；每行可以横向滚动。组合键操作保持软键盘输入焦点，菜单按钮打开桌面工具栏。

手势包括点按左键、单指拖动、长按右键和双指滚动。只有物理桌面画面支持独立捏合缩放（当前显示模式基础上的 1–4 倍），放大后双指平移查看画面局部；缩回 1 倍后双指平移仍发送远端滚动。缩放与平移不改变底栏大小、粘滞键、软键盘状态或远端分辨率，输入坐标按放大后的画面换算。切换桌面、断开连接或主动切换显示模式时清理局部缩放。取消手势时不产生残留点击或按键。

PC 与移动端在页面内拦截浏览器捏合、Ctrl/Command 加滚轮以及缩放快捷键，移动端声明固定页面缩放比例并避免输入框聚焦放大。PC 触控板捏合位于物理画面内时同样缩放画面；其他区域只拦截页面缩放。远端应用仍可收到其键盘组合键。浏览器自身菜单和系统辅助放大由浏览器或操作系统管理。

文字通过本地输入代理提交，支持中文组合输入去重、普通文字、粘贴、退格和 Enter。键盘开关与缩放只调整本地可见区域，不触发远端分辨率变更；正常窗口调整仍沿用已有的分辨率跟随设置，物理桌面保持原分辨率。

虚拟桌面启用跟随窗口时，根据设备像素比使用最高 3 倍采集密度，同时设置合成器缩放，保持文字、控件和桌面逻辑尺寸。超过 3840×2160 编码范围时降低采集密度；输出尺寸保持适合 H.264 的偶数像素。手动调整分辨率沿用 1 倍缩放；旧服务不支持缩放能力时回退原有尺寸请求。物理桌面保留显示器原有分辨率和缩放。

实现验证包括前端回归、输入组合及手势测试，以及浏览器移动视口中的真实候选桌面操作。浏览器移动视口无法代替实体手机的系统键盘：iOS/Android 的软键盘弹出、收起、输入法候选栏与安全区仍需在手机上手动确认。

## 全键盘模式

在“外观与语言”的主题选项下方可以开启 全键盘模式，默认关闭并记住本机浏览器的选择，仅在手机、平板和折叠屏等移动触摸设备上启用。开启后，上半屏显示远程桌面，下半屏的键盘使用类似 iPhone 深色键盘的灰色色块、轻微圆角和小间隔，不使用描边或分隔线；原有快捷键底栏隐藏。触控板没有背景色，正中央显示“触控板”提示，文字不阻挡点按和滑动。屏幕按键宽度不小于高度，键盘根据可用宽度限制行高，剩余高度全部留给下方触控板，不另留掌托边框；方向键保持与字母键接近的尺寸，倒 T 形下排从右侧延伸一行。面板右上角保留菜单和 LightOS 主页入口，连接未就绪时仍可使用。

按键语义使用 Omarchy/Linux 的 Super、Alt 和 Ctrl。可按住修饰键组成快捷键，也可轻点修饰键后再点目标键；例如 Super 后点空格可打开远端菜单。Fn 已移除，其位置并入空格键；Esc 与 F1–F12 在横竖屏都保留直接入口。按键名称统一单词首字母大写，单内容独立居中，双内容作为一组水平、垂直居中，按实际字形边界平衡上下和左右留白。触控板支持单指移动、轻点左键、双指轻点右键、双指滚动、按住或双击后按住拖拽；物理桌面还可双指缩放画面。关闭模式、打开菜单或失去焦点时清理按键与拖拽状态。

右上角地球图标可切换系统输入法，用于中文等文字输入。系统键盘展开后同时隐藏 全键盘模式 按键和触控板，面板收缩为仅保留键盘开关、菜单与主页的按钮栏；收起系统键盘后恢复完整面板。

移动端全屏会收起系统键盘并隐藏底栏和全键盘模式面板，让画面使用整个可见区域。右上角键盘图标在两秒后自动隐藏，点击页面任意位置会重新显示并重新计时；点击图标可开关系统键盘。物理桌面保持比例放大铺满，可以双指移动查看局部或缩放；虚拟桌面继续跟随可用区域。系统键盘展开后操作栏位于键盘上方，退出全屏恢复原布局。部分宿主不支持浏览器原生全屏时，采用覆盖网页可见区域的布局。
